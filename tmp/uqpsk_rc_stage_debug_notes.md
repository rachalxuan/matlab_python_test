# UQPSK RC 256 Byte 只读分级诊断

运行 `codex_uqpsk_rc_stage_debug_v1.m`，固定原失败配置及种子917，增加同配置RRC对照。
每种成形各运行debug关闭/开启两次，比较BER、FER、完整覆盖结构、逐帧时间记录、相位选择和分组选择；不一致即停止诊断，保存现场。

本次没有开启 `debugSynchronizationChain`：该旧开关在部分路径也会参与ASM诊断分支。新增 `debugUQPSKPulseStages` 只抓取滤波后、定时后、载波后、被选中解调假设的软比特及原有BER acquisition门限结果，不改变算法决策。

## 输出含义

- `[1 CONFIG]` 固定条件，不改变预热长度或增加FEC。
- `[2 NON-INTERFERENCE]` 开关debug前后统计完全一致才为1。
- `[3 FRONT END]` CFO、各级长度、接收机选定相位/分组及PLL统计。
- `[4 STAGES]` 仅离线用TX真值对齐各级信号。在后60%位置固定4096符号窗口选择一个延迟、一个复增益；之后所有窗口使用同一结果。不能逐窗口消除相位或重新对齐来掩盖滑移。`AnchorCorrelation`低时不能相信该级真值比较；`FixedLag`触到±128搜索边缘时应扩大离线诊断范围，而不是改接收器。
- `SER_pct`为复符号I/Q符号判决错误比例（Q尚未按两符号合并），不是译码BER。`BestLocalLagDelta`仅作±2符号的局部错位提示，不用于修复或重算主要指标。MF是固定抽样栅格的离线探针，不代表真实定时环输出。非整数符号/帧导致符号窗口与帧界约有1符号量化差。
- `[5 SOFT + ASM]` 选中分组/相位的真实原始软输出，按原有码约定soft>0为1。仅一个后段4096-bit窗口确定固定bit延迟；分别统计每帧32-bit ASM和2048-bit TF错误。不在每帧重新挑选相位、极性或参考帧。`LateAnchorBER`非零时先检查对齐可信度。这里与逐帧译码统计处于不同阶段，不能只看二者数值相等就断言同一责任层。
- `[6 COUNTING GATE]` 接收机已经选中的假设，打印物理参考帧、VCFC、实际错误、连续可靠帧数、BER acquisition以及计数原因；此acquisition门限属于评估统计逻辑，不等价于物理帧同步锁定。
- `[7 TIMELINE]` 包括已恢复未比较帧的ObservedErrorBits，不能把未比较理解成零错误。

TX参考只在接收机返回以后由脚本读取，用于离线尺子，不反馈至滤波、定时、载波或ASM。现有接收机原本的假设选择/帧关联方法不在本轮修改范围。

返回 `UQRC_Debug.Runs{1}` 为RC，`{2}` 为RRC。日志按时间戳命名，原始各级复样本、定时插值量、软比特、门限表及完整原日志保存到控制台 `[SNAPSHOT]` 打印的独立 v7 MAT 文件。保存失败只警告，不中断 RRC 对照。不要求已知失败用例BER=0，不会把诊断完成写成回归通过。

注意：R2022a `comm.SymbolSynchronizer` 返回的第二个输出在实现中是 `pMu`（归一化分数插值间隔），不是 Gardner TED 的原始误差；不能把它的 RMS 直接解释为定时失锁程度。2026-09-25 的同输入 A/B 结论见 `uqpsk_gardner_replay_findings.md`。

## 本机验证（2026-09-24）

RC/RRC两种配置均通过debug开关不干扰断言，RC原118/120、8 bit现象完整复现；RRC仍为120/120、BER=0。

RC的固定栅格匹配滤波输出在前24个诊断窗口均为零符号判决错误（仍有约15% EVM）。定时后第10/12/17窗口出现32/2/4符号错误，载波后为33/3/4，另第11窗口从0变成1。这支持先检查RC与现有Gardner定时捕获/跟踪的适配，再查载波环的附加影响；不能直接据此认定具体环路参数或更新公式错误。这里的符号错误数不等于Q合并后的bit错误数。

软解调的第10帧TF有33 bit错误，且ASM为0错；第11/12/17帧TF分别有1/3/4错，ASM也为0错。计数表明确说明第9/10帧仅因连续可靠帧数为1/2、未达到3而未计数，第11帧才打开BER acquisition。第9/10帧均已有物理参考帧对应，不是被信道抹去的帧；第10帧的33个错误不能被说成不存在。统计门限和接收端误码是两个需要分开处理的问题，本轮未修复其中任何一个。
